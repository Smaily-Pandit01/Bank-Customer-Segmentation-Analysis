# Bank Customer Segmentation Analysis via Power BI

# Project Overview
The Bank Customer Segmentation Analysis project was developed using Power BI to analyse customer demographics, transaction behaviour, customer segments, profitability, and risk indicators.

The project transformed raw banking transaction data into an interactive dashboard that provided meaningful insights into customer behavior and helped identify different customer segments based on their transaction patterns.

# Project Objectives
- Analyze customer demographics such as age, gender, and location.
- Understand transaction volume and transaction amount patterns.
- Segment customers based on their Recency, Frequency, and Monetary (RFM) behavior.
- Analyze revenue and profitability indicators across customer segments.
- Identify risk patterns among different customer groups.
- Create an interactive dashboard for easy analysis and decision-making.
